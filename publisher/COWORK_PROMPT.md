## 追記した共通ブロック

```
【公開版の自動投稿（note・X）】
公開版の「# ① X投稿スレッド」の行から末尾までは、GitHub の仕組みがそのまま note と X に投稿します。人の手は入りません。
- 書式（機械が読むので厳守）:
  - `# ① X投稿スレッド（Nポスト構成）` の下に、各ポストを `### 1/N` `### 2/N` … の見出しで区切る
  - 各ポストは全角140字以内（半角英数・記号は0.5字、改行・ハッシュタグ込み）。超えると機械的に分割されて読みにくくなる
  - URLは書かない。note を公開できた場合だけ、仕組み側が最後のポストに記事リンクを自動で付ける。
    最後のポストはリンクがなくても意味が通る文にする（「全文👇」のようにリンク前提で終えない）
  - `# ② note記事` の下に `## タイトル`（次の行にタイトル1行）、`## 本文`（以降すべて本文。見出しは `###`、
    箇条書き・太字・区切り線は可、表は使わない）
- 送信: Gmail の `send_message` で次の1通を送る（これが投稿の引き金。送らなければ何も投稿されない）
  - to: ryotaozawa1010@gmail.com
  - subject: [PUBLISH] YYYY-MM-DD_weekday（週末版は _weekend。日付は配信日＝日曜）
  - body（プレーンテキスト。このメールに限り Markdown をそのまま入れる。htmlBody は使わない）:
      TOKEN: <PUBLISH_TOKEN と同じ値>
      -----BEGIN-----
      （公開版の「# ① X投稿スレッド」の行から末尾まで。1文字も変えない）
      -----END-----
  - 1日1通だけ。送信に失敗したら再送は1回まで
```
