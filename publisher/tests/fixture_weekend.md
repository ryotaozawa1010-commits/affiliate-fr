# ② note記事

## タイトル

**【米国株】2026/09/27 今週の振り返りと週明けの展望**

## 本文

金は週足 −1.95% で下げました。でも、この1週間でいちばん記録に残しておきたいのは値幅ではなく、**「答えは最初から一番上の階層にあった」**という話です。

今週わたしは4回、金の説明変数を探して枠組みを乗り換えました。月曜は「地政学プレミアム」、火曜は「メタル間の相対」、水曜は「日中の支持水準」、木曜は「入札イベント」。**そして4回すべてが翌日に否定されました。** 週が終わってから週次で集計してみたら、金 −1.95% は10年実質金利 +16bp だけでほぼ説明がついてしまった（感応度 0.122%/bp）。つまり、毎日新しい説明を探していた時間は、まるごと無駄だったわけです。

### 今週の最重要データ：上昇の全額が実質金利だった

数字で書きます。

- 名目10年：5.00% → **5.165%（+16.5bp）**
- 10年TIPS（実質金利）：2.68% → **2.84%（+16bp）**
- 10年BEI（市場の期待インフレ）：2.32% → **2.325%（+0.5bp）**

**名目金利の上昇分がほぼ丸ごと実質金利で、期待インフレは動いていません。**

これは先週の自分の読みを否定する材料でもあります。先週は「ミシガンの1年先インフレ期待 4.6% と消費者信頼感 48.1 の同時進行＝スタグフレーション」と整理していました。でも**サーベイのインフレ期待（4.6%）と市場のインフレ期待（2.33%）は完全に乖離していて、市場は「一時的」に投票している。** アンケートで人が答えるインフレ期待と、実際にお金を賭けている人のインフレ期待は、別物として扱わないといけません。

そして実質金利が上がるというのは、金にとって「持っているだけで機会費用が増える」という一番わかりやすい逆風です。金が下げた理由は、これだけで足ります。

### 週足の形 ─ 下降トレンドは「まだ」成立していない

金の週足は **始 4,363.44 / 高 4,373.93 / 安 4,241.13 / 終 4,287.15** の陰線でした。

注目してほしいのは高値と安値の関係です。**高値は 4,390.61 → 4,373.93 で5週連続の切り下げ。でも安値は 4,237.44 → 4,241.13 で切り上がっています。** ダウ理論の定義では、これは上昇でも下降でもない「インサイド」の形。つまり**週足レベルでは方向が出ていない。**

ローソクの中身も面白い形をしていました。上ヒゲ 10.49・下ヒゲ 46.02。**週の頭から売られて一度も上を試さず、後半に買い戻された。** 売り圧力は明確に強いのに、下値は硬い。

だから週明けに見るべき水準は、ほとんど1本に絞られます。**4,237–4,242。** 週の安値 4,241.13 と前週安値 4,237.44 が重なる二重底で、**ここを2営業日連続の終値で割ったとき、はじめて週足の下降トレンドが成立します。** 逆に上は 4,307.90（9/25高値）を日足終値で明確に超えたかどうか。この2つの外側に出るまでは、たいして情報は出てきません。

### 週末に出た「価格に入っていない材料」が2つ

ここが週明けのいちばんの不確実性です。

**① ホルムズ海峡：トランプ氏がイランの提案を拒否しました。** イラン側は9/25にUNGAで「受諾から7日で海峡を再開する」という段階案を公表していて、カタール経由で米側に伝えていました。それをトランプ氏が拒否し、**中間選挙後の空爆再開を側近に示唆した**とWSJが報じています。重要なのはタイミングで、**金曜の WTI −2.33% は「合意期待」を織り込んで引けている**ということ。拒否はまだ価格に入っていません。→ 原油と金に上方。

**② 米中が約300億ドル規模の関税引き下げとAI対話で合意しました（9/26発表）。** → 株・銅・半導体に上方、金には下方。

**この2つは金に対して逆向きに効くので、週明けの窓そのものは小さいと見ています。** 金の週末実勢は 4,278.70（金曜終値から −0.20%）で、想定する窓は −0.3% 〜 +0.8%、中心は上方向に +0.2〜0.5% 程度。

ただ、**打ち消し合うことは「動かない」ことを意味しません。** 寄りは両方向に振れてから収束する形になりやすい。だから週明けの最初の1時間は、**どちらが勝ったかを判定するためだけに見る**のがいいと思っています。判定材料は単純で、**原油が +3% 以上の上窓をつけながら株先物もプラスなら「ホルムズ＞米中」。原油が上がらず株先物だけがプラスなら「米中＞ホルムズ」。**

### 米国株 ─ 指数は上げたのに、上げたセクターは4本だけ

S&P500 +1.20%・NASDAQ100 +3.31%。数字だけ見れば良い週です。でも**11セクターのうち上げたのは4本だけ**でした。

XLK +3.64%・XLC +2.27%・XLV +1.76%・XLI +0.67% ↔ XLU **−3.16%**・XLE −2.96%・XLRE −1.47%・XLF −1.47%。**首位と最下位の差は 7.4pt。** そしてラッセル2000 は −0.74% で、6週間ずっと超えられない水準をまた超えられませんでした。**上げは半導体と通信に集中していて、幅がない。**

個別で気になっているのは2つ。**UAL** は終値が200日線を +4.57% 上回り、2週間続いた「200日線の下に滞留」がようやく解消しました。コンセンサスも Strong Buy に格上げ。ただ**ホルムズ拒否で原油が上がるなら、航空株には直接の逆風**なので、素直に買える形ではありません。もう一つは **CI**。ファンダはPEG 0.84・ROIC 13.39%・PB 1.68 と全部きれいなのに、200日線を 2.82% 割っているだけで対象外になっている銘柄です。**9/30 の Investor Day が唯一のカタリスト**で、ここで終値を回復できるかを見ています。

### 予測の方針を1つ変えました

セクター予測について、白状しておきます。**XLU と XLRE を「もう十分下がった／金利上昇は織り込み済み」という理由で流入予測にして、3週連続で外しました。** 今週は特にひどくて、**予測した第1候補と第2候補がそのまま最下位圏を占めました。**

原因はわかっていて、**「織り込み済み」は検証できない条件だから**です。金利が上がり続ける局面では、いくら下げても「まだ織り込み途中」と言えてしまう。反証されない予測は予測ではありません。

**なので、この論理は破棄します。** これからは金利の方向に素直に従って、反転条件を数値で置く。XLRE なら「30年 5.35% 割れ」、XLU なら「10年 5.00% 割れ」。**金利が反転した週には全滅する予測になりますが、それは承知のうえで、検証できる形にすることを優先しました。**

### BTC ─ 週足は上昇トレンド成立、でもフローが減衰している

BTC の週足は高安とも2週連続の切り上げで、**上昇トレンドが成立しています（+3.16%）。** ただ中身は弱い。**上ヒゲ 3,657 が実体 2,864 より長く、下ヒゲは 86 しかありません。** 週の全値幅が月曜の急騰（+8.2%）で作られて、火曜以降5日かけてその 55% を戻した形です。

そして現物ETFフローが同じことを言っています。**+999.0 → +714.7 → +346.9 → +190.7 → +134.5（百万ドル）と5日連続で単調に減っていて、金曜のペースは週初の 13.5%。** 週合計は +23.86億ドルで前週のほぼゼロから劇的な改善ですが、**合計だけを見て「強い需要」と読むと誤ります。** 上抜けにはフローの再加速が必要条件で、いまその兆候はありません。

### 来週のスケジュールで、1つだけ覚えておくこと

**9/30（水）の 14:15–16:15 Paris（08:15–10:15 ET）。** この90分に ADP（予想+70K・前回+38K）・コアPCE（YoY 3.4%）・GDP確報・シカゴPMI（予想51.3・前回46.9）が集中します。加えて**四半期末リバランス**で、引け前1時間に機械的な「株売り・債券買い」が出やすい日でもあります。**この時間帯の値動きをファンダの変化として読まないこと。**

10/2（金）14:30 の雇用統計（NFP +100K・失業率 4.2%）も同じ扱いで。ミシガン 48.1 の後で「消費は弱いが雇用は？」の最終回答が出ます。

なお、**10月1日の政府閉鎖リスクはありません。** FY2027 の暫定予算は9/2に署名済みで、次の資金切れは12月11日です。「10月1日＝会計年度初日」という形だけを見てリスクを作らないように。わたしも今週いったんこれをリスク欄に書きかけて、一次確認で消しました。
